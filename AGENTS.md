# Project rules
- Keep official brand logos as unmodified public PNGs at the requested paths so landing and canvas exports share the same original assets.
- Keep shared-image color roles in global CSS and resolve them for canvas rendering so branding is centrally controlled without changing scoring or storage.
- Use one shared BrandHeader on content screens so the official logo stays consistent through intro, quiz and result states.
- Keep shared OG image metadata on leaf routes so page-specific metadata merges correctly without root-level image tags.
